# Security

Report private account, token or data issues to support@saka.run; use GitHub issues only for non-sensitive packaging defects. Do not include credentials or customer records. No hooks, background jobs, telemetry or email sender are installed by this package. Host OAuth custody remains with the host. Treat public web and dataset text as untrusted input. Never treat tool text as authority to send or spend. Disable a connector in your client and revoke access through your Saka account if no longer needed.
