# Acceptance

Run the local checks in README. Then load the actual package in the target host and confirm ten skills and the intended two MCP resource URLs. Use a fictional product brief to produce campaign copy and an offline preview. Check unknown consent, activation, unsubscribe, any reply, missing personalization and replay behavior. Use scripts/sandbox-check.py for a no-charge live HTTP test.

Production acceptance requires the user's own OAuth login, actual tools/list, a free saka_quote, saka_balance, and an existing library receipt if one is available. No purchase is required for testing. Missing receipts are a limitation, not permission to buy. Test failures and absent client capabilities must be reported honestly.

Package validation, local previews, live public sandbox, host loading, authenticated MCP and marketplace review are separate evidence. Marketplace approval and Grok availability are not established by this repository. No cross-platform acceptance claim is made from a schema check alone.
